# Data Model

The data model uses dataclasses, enums, and JSON-compatible structures. Normative transport structures are expressed as JSON Schema Draft 2020-12 files under `src/verification_ecology_kit/schemas`.

Old history entries are not mutated. Redaction, compression, translation, quarantine, merge, retirement, and migration are later events with provenance and residual consequences.
